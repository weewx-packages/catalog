# Installation guides

These guides describe the published packages and their configuration with stock
WeeWX. Repository search and updates use the experimental
[standalone package manager](https://github.com/weewx-packages/weewx-package-manager).

For source mirrors, our installation guides live on a separate documentation
branch. The upstream source branches retain their original files.
